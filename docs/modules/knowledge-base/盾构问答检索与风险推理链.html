盾构问答逻辑：从“问题分类”走向“可执行风险推理”

目标不是给问题贴标签，而是确定查找对象、补齐工况、建立证据链并产生可审核的控制候选。

1. 问题解析

对象：土压、推速、姿态、注浆等

动作：查询、诊断、调整、处置

2. 工况补齐

环号、地层、设备、工序

当前值、趋势、报警与历史动作

3. 检索路由

规范：强制边界

案例：相似处置

论文：机理与判断思路

4. 风险因果链

现象 → 诱因 → 后果

证据支持与反证

缺失条件触发追问

5. 硬约束裁决

规范、项目规则、设备联锁

任何越界直接否决

6. 候选指令

原值、新值、变化率、有效范围

依据、预期影响、回滚条件

7. 闭环执行

司机确认 → 下发

实时监控 → 成功/中止/回滚

国家规范：强制约束

提取适用范围、条款号、限值、禁止事项和版本状态。

作用：可以否决候选参数。

工程案例：条件性经验

提取地层、设备、工序、异常、措施、结果和副作用。

作用：只有条件相似时才可参考。

论文：解释性证据

提取研究条件、方法、因果假设、结果、局限和适用范围。

作用：支持判断思路，不能单独形成强制指令。

知识库产生候选决策；确定性规则负责安全裁决；司机确认后由执行智能体下发。
