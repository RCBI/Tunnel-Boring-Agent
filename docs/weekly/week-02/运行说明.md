# 盾构播报机器人 demo 程序说明

## 1. 程序作用

本 demo 用于验证“从 19 号线 22 标历史掘进数据文件读取指定环号数据，生成环总结 + 安全警示播报”的最小闭环。

程序默认读取同目录下的 SQL 文件：

```text
数据文件：mb_data_his_auto历史掘进数据.sql
数据表：mb_data_his_auto
```


## 2. 文件结构

```text
demo/
├── broadcast_demo.py
├── README.md
├── mb_data_his_auto历史掘进数据.sql
├── mb_data_auto.sql
├── 控制目标表.sql
└── outputs
```
其中 `mb_data_his_auto历史掘进数据.sql` 是程序默认读取的数据文件，`outputs` 中的文件由程序运行后自动生成。
备用方案为程序直接进入本机本地SQL数据库读取所需文件。

## 3. 运行环境

需要本机具备：

- Python 3.9 或更高版本；
- `broadcast_demo.py` 与 `mb_data_his_auto历史掘进数据.sql` 位于同一目录；

## 4. 在 PyCharm 中运行

1. 打开 PyCharm。
2. 选择 `File -> Open`，打开目录：

```text
...\demo
```

3. 打开 `broadcast_demo.py`。
4. 右键文件空白处，选择 `Run 'broadcast_demo'`。
5. 运行完成后，查看终端输出和 `outputs` 文件夹。

如需指定其他环号，在 Run Configuration 的 Parameters 中填写：

```text
--ring 1045
```
## 5. 输出内容

程序会输出三版播报：

- 简约版；
- 完整版；
- 详细说明版。

同时生成：

```text
outputs/ring_1028_broadcast.md
outputs/ring_1028_broadcast.json
```

当指定其他环号时，输出文件名会随环号变化，例如：

```text
outputs/ring_1045_broadcast.md
outputs/ring_1045_broadcast.json
```

## 6. 常见问题

### 6.1 提示找不到 SQL 文件

确认 `mb_data_his_auto历史掘进数据.sql` 是否和 `broadcast_demo.py` 位于同一目录。

### 6.2 提示未查询到环号

说明输入的 `AVBA10` 在当前 SQL 文件中不存在。当前已知19 号线 22 标样例数据可用环号为：

```text
1028-1047
```

### 6.3 程序运行时间较长

SQL 文件较大，程序需要解析 `mb_data_his_auto` 的 INSERT 数据。首次运行约需数秒，属于正常现象。
