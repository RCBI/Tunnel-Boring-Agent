# 盾构播报机器人新版设计方案

> 课题：隧道掘进智能体  
> 模块：盾构播报机器人 / 掘进实时播报智能体  
> 负责人：王英杰  
> 周次：第三周  

## 1. 方案概述

盾构播报机器人面向盾构司机、现场技术人员和管理人员，承担“每环完成后主动说明、下一环开始前主动提醒、出现风险时主动提示”的高频服务能力。第三周设计在第二周“环总结 + 安全警示”基础上进一步调整，播报内容从字段罗列转向面向施工交流的短句式、分层式表达，重点形成三类模板：

| 模板 | 主要目的 | 输出形式 |
| --- | --- | --- |
| 总结型 | 说明上一环完成环的工况、控制效果和现场关注项等 | 简约版、详细版 |
| 预报型 | 提醒下一环启动前需要关注的地质、线型、自动驾驶率和安全延续项等 | 简约版、详细版 |
| 安全警示型 | 对报警位、连续参数阈值和风险关注项进行提示 | 简约版、详细版 |

程序采用 Python 实现，直连读取 MySQL 实时数据库。`mb_data_auto` 作为实时数据表，程序读取实时数据；`mb_data_his_auto` 作为历史数据表，用于安全阈值参考。

## 2. 数据输入与处理口径

### 2.1 数据来源

| 表 | 作用 | 使用方式 |
| --- | --- | --- |
| `mb_data_auto` | 实时数据表 | 读取实时数据作为主要目标数据 |
| `mb_data_his_auto` | 历史数据表 | 参考历史数据计算连续参数关注阈值和严重阈值等指标 |

### 2.2 加工指标

模板不直接堆叠字段，而是将实时数据加工成施工人员更容易理解的结论。

| 加工指标 | 数据来源概括 | 用途 |
| --- | --- | --- |
| 掘进完成情况 | 环号、时间、里程、推进净行程 | 判断播报目标环，说明完成状态 |
| 工况概况 | 推进速度、总推力、刀盘扭矩、土压 | 说明本环关键施工状态 |
| 控制效果 | 前后端姿态偏差、推进节奏、土压和负载变化 | 生成“总体稳定 / 存在关注项”等表达 |
| 安全状态 | 报警位、历史阈值、连续参数是否越限 | 生成正常、关注、警示等提示 |
| 下一环关注项 | 上一环风险延续、实时状态、地质/线型/自动驾驶率占位 | 形成下一环启动前提醒 |

注：自动驾驶实现率、地质情况和线型情况仍需正式接口或统一定义。

## 3. 播报触发条件

### 3.1 推荐触发逻辑

| 触发方式 | 说明 | 优先级 |
| --- | --- | --- |
| 环号变化触发 | 当实时表环号由 N 变化为 N+1 时，判定 N 环已完成，触发 N 环总结和 N+1 环预报 | P0 |
| 推进净行程触发 | 当推进净行程达到接近一环长度且状态趋于稳定时，触发当前环总结 | P1 |
| 报警事件触发 | 报警位触发或连续参数达到关注阈值时，立即生成安全警示 | P0 |
| 人工或中枢触发 | 司机、中枢或管理端请求指定环播报，用于复盘和补报 | P1 |

当前程序读取实时表数据生成播报，后续联动时，可在中枢或数据服务层增加环号变化监听，形成自动触发机制。

## 4. 三类播报模板

### 4.1 总结型

**目的**：在上一环完成后，用短句说明本环关键工况、控制效果和需要现场补充记录的问题。

**输入数据项**

| 类别 | 内容 |
| --- | --- |
| 环号与进尺 | 环号、推进净行程、里程 |
| 工况参数 | 推进速度设定、土压、总推力、刀盘扭矩 |
| 控制效果 | 姿态控制结果、负载与土压状态 |
| 现场关注 | 开环初期土压与姿态稳定、软硬不均、渗漏、异响、管片拼装、纠偏异常 |

**简约版**

```text
第 {ring_no} 环完成。推进净行程 {stroke_max}，速度设定 {speed_set}，左右土压约 {left_pressure}/{right_pressure}。{posture_result}，{load_pressure_result}；本环需要关注的问题为{attention_items}。
```

**详细版**

```text
【工况概况】第 {ring_no} 环已完成，推进净行程 {stroke_max}，里程约 {mileage}，推进速度设定 {speed_set}。当前土压左/右约 {left_pressure}/{right_pressure}，总推力 {thrust}，刀盘扭矩 {torque}。
【控制效果】本环{drive_rhythm}，{posture_result}。自动驾驶实现率为 ……。
【问题与关注】本环负载与土压{load_pressure_result}，需要关注{attention_items}。如现场存在软硬不均、渗漏、异响、管片拼装或纠偏异常，请补充现场反馈。
```

**程序输出示例**

```text
第 1088 环完成。推进净行程 1211，速度设定 21，左右土压约 3.6/3.2。姿态控制总体稳定，未见明显异常；本环需要关注的问题为开环初期土压与姿态稳定。
```

**程序输出示例**

```text
【工况概况】第 1088 环已完成，推进净行程 1211，里程约 6846.825，推进速度设定 21。当前土压左/右约 3.6/3.2，总推力 0，刀盘扭矩 0。
【控制效果】本环基本平稳，姿态控制总体稳定。自动驾驶实现率为 ……。
【问题与关注】本环负载与土压未见明显异常，需要关注开环初期土压与姿态稳定。如现场存在软硬不均、渗漏、异响、管片拼装或纠偏异常，请补充现场反馈。
```

### 4.2 预报型

**目的**：在下一环启动前，结合上一环状态提醒需要提前关注的工况、地质、线型和安全延续项。

**输入数据项**

| 类别 | 内容 |
| --- | --- |
| 下一环编号 | 当前环号 + 1 |
| 上一环衔接 | 掘进节奏、姿态控制、负载与土压状态 |
| 下一环预报 | 地质、线型、自动驾驶率 |
| 安全提醒 | 土压突变、姿态偏差扩大、负载升高、报警位触发 |

**简约版**

```text
下一环为第 {next_ring_no} 环，需重点关注{forecast_focus}。结合上一环{previous_result}，开环初期建议重点观察土压、姿态和负载变化；地质……，线型……，自动驾驶率……。
```

**详细版**

```text
【启动前概况】上一环中{previous_result}。因此下一环开始后，应重点核对上一环关注项是否延续，避免开环初期偏差继续扩大。
【下一环预报与关注】下一环为第 {next_ring_no} 环，需重点关注{forecast_focus}。地质情况为……，线型情况为……，自动驾驶率预期为……；开环初期优先观察土压建立、姿态变化和负载响应。
【安全提醒】若下一环出现土压突变、姿态偏差扩大、刀盘负载升高或报警位触发，应优先提示现场人员介入判断，并由中枢记录处置过程。
```

**程序输出示例**

```text
下一环为第 1089 环，需重点关注开环初期土压与姿态稳定。结合上一环掘进节奏基本平稳，姿态控制总体稳定，负载与土压未见明显异常，开环初期建议重点观察土压、姿态和负载变化；地质……，线型……，自动驾驶率……。
```

```text
【启动前概况】上一环中掘进节奏基本平稳，姿态控制总体稳定，负载与土压未见明显异常。因此下一环开始后，应重点核对上一环关注项是否延续，避免开环初期偏差继续扩大。
【下一环预报与关注】下一环为第 1089 环，需重点关注开环初期土压与姿态稳定。地质情况为……，线型情况为……，自动驾驶率预期为……；开环初期优先观察土压建立、姿态变化和负载响应。
【安全提醒】若下一环出现土压突变、姿态偏差扩大、刀盘负载升高或报警位触发，应优先提示现场人员介入判断，并由中枢记录处置过程。
```

### 4.3 安全警示型

**目的**：当报警位触发或连续参数超过关注阈值时，提示风险对象和现场判断边界；未触发风险时，输出正常状态和下一环关注项。

**输入数据项**

| 类别 | 内容 |
| --- | --- |
| 报警状态 | 土压异常、刀盘扭矩注意、滚动异常、非常停止等报警位 |
| 连续参数 | 姿态偏差、土压差、总推力、刀盘扭矩 |
| 阈值规则 | 1028-1047 环历史数据均值与标准差 |
| 现场判断 | 异响、渗漏、管片拼装异常、司机感知异常 |

**阈值规则（假设，可替换为实际规则）**

```text
关注阈值 = 1028-1047 环历史数据对应指标均值 + 2 × 标准差
严重阈值 = 1028-1047 环历史数据对应指标均值 + 3 × 标准差，或严重报警位触发
```

**简约版**

```text
安全提示：第 {ring_no} 环{risk_object}处于{risk_level}状态，{risk_basis}。下一环需重点关注{attention_items}，必要时由现场人员或判断模块进一步确认。
```

**详细版**

```text
【安全警示】第 {ring_no} 环触发{risk_level}级提示，风险对象为{risk_object}。
【阈值判断】报警事件状态为{alarm_status}。
【现场判断】下一环或当前环建议关注{attention_items}，如现场存在异响、渗漏、管片拼装异常或司机感知异常，请补充反馈。该条播报不代表最终安全裁决，请现场人员介入判断。
```

**程序输出示例**

```text
安全提示：第 1088 环关键监测指标处于正常状态，关键风险指标未超过当前关注阈值。下一环需重点关注开环初期土压与姿态稳定，必要时由现场人员或判断模块进一步确认。
```

```text
【安全警示】第 1088 环触发正常级提示，风险对象为关键监测指标。
【阈值判断】报警事件状态为未见已关注报警位触发。
【现场判断】下一环或当前环建议关注开环初期土压与姿态稳定，如现场存在异响、渗漏、管片拼装异常或司机感知异常，请补充反馈。该条播报不代表最终安全裁决，请现场人员介入判断。
```

## 5. 程序与输出结构

程序位置：

```text
docs/weekly/week-03/broadcast_demo_mysql.py
```

输出位置：

```text
docs/weekly/week-03/
```

输出文件：

| 文件 | 内容 |
| --- | --- |
| `previous_ring_summary.md` | 上一环总结 Markdown |
| `previous_ring_summary.json` | 上一环总结 JSON |
| `next_ring_forecast.md` | 下一环预报 Markdown |
| `next_ring_forecast.json` | 下一环预报 JSON |
| `safety_warning.md` | 安全警示 Markdown |
| `safety_warning.json` | 安全警示 JSON |

Markdown 文件仅保留播报内容，不包含测试说明、输入表格或触发日志。JSON 文件仅保留 `brief` 和 `detail` 两个字段，便于中枢、APP 或语音服务读取。

## 6. 后续对接事项

| 事项 | 说明 |
| --- | --- |
| 环完成触发 | 需要确认实时表环号变化、推进净行程或工序状态哪个作为自动触发源 |
| 地质与线型数据 | 下一环预报中的地质、线型仍需接入正式资料或知识库 |
| 自动驾驶实现率 | 需要统一口径，可按自动驾驶有效时长、自动推进距离或自动控制执行记录计算 |
| 安全阈值 | 当前采用历史统计阈值，后续需由平台规则、现场经验或安全规范确认 |
| 中枢与 APP 联动 | 需要确认播报文本由播报机器人直接输出，还是由中枢统一改写后展示 |
